## #19 PyQt6ElaWidgetTools（编译 pyd）：eTheme / eApp 单例包装 __getattr__ → C++ getInstance() 链访问违规，进程死亡（app 空闲时偶发）

- 库/组件：PyQt6ElaWidgets0.13.0（2026-10-21内网镜像构建，ElaWidgets.pyd 6.6 MB）单例访问链：__init__.py的__wrapsingleton包装类__getattr__(eTheme.<attr>/eApp.<attr>均经此路径)→C++ElaTheme.getInstance() / ElaApplication.getInstance()（或其返回对象上的属性访问）。 

• 上下文（不断因果）：同进程会话内、AV 之前，MATLAB COM 线程（matlab_tools_connect_to_matlab 轮询）累计 59 次 0x800706ba / 0x800706be（E_UNEXPECTED/E_ABORT）faulthandler 转储——该码非致命，CPython faulthandler 会照写全线程 dump 后放行异常，Python 侧 except Exception 全部接住、进程存活（日志观感吓人、实非崩溃；tool_calls 日志全程无 matlab_start 完成记录，即 COM 引擎始终未连上——当时本机 MATLAB COM 服务端处于坏状态）。AV 是本会话唯一真正致命的异常。 

- 复现：暂不可复现（首现；无最小复现，无法定位命中异常单例状态的具体控件 / 主题令牌调用；后续再发时 crash_diagnostics 的全线程栈可辅助定位）。 

复测（2026-10-23）：0.13.0 新 pyd（2026-10-22 23:24 重构建）下 probes/ela_singleton_smoke.py（真实 QApplication + 可见窗口，300 轮主题切换 + 并发 eTheme.getThemeColor / ElaTheme.getInstance() / ElaApplication.getInstance() 单例访问，4.6 s）无 AV。冒烟通过不证明已修（空闲期偶发 AV）；库侧 tools/docs/crash-diagnostics.md 仍在向宿主征集真实崩溃的 faulting module + offset 取证，本条保持 open。 

期望行为：getInstance() 类单例访问器在应用空闲期不应 AV；至少 C++ 侧对单例状态（未初始化 / 已析构）有判空保护，异常时抛出 Python 异常而非原生崩溃。 

- 项目侧临时规避及移除条件：无（空闲期偶发、宿主侧无法规避；crash_diagnostics 保底取证）。若稳定复现某控件/某操作路径，再评估项目侧绕行。
